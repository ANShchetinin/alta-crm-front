# AltaCRM Frontend

AltaCRM — это B2B SaaS CRM-система для управления клиентами, заказами (Канбан-доска) и складским учетом, спроектированная с поддержкой Multi-Tenancy (изоляция данных по компаниям/арендаторам). 
Данный репозиторий содержит клиентскую (frontend) часть приложения с поддержкой PWA (Progressive Web Application).

## 🛠 Технологический стек
- **Библиотека**: React 18
- **Язык**: TypeScript
- **Сборщик**: Vite
- **PWA**: `vite-plugin-pwa`, Workbox Service Worker
- **Стилизация**: CSS Modules / Vanilla CSS
- **Состояние**: Zustand
- **Маршрутизация**: React Router v6
- **Иконки**: Lucide React
- **Интернационализация**: i18next (React-i18next)
- **HTTP клиент**: Axios

## 🚀 Особенности
- **Multi-Tenancy UI**: Полностью изолированные рабочие пространства в зависимости от авторизованного пользователя и его JWT токена.
- **PWA & Мобильная оптимизация**:
  - Поддержка установки на домашний экран (Add to Home Screen) на iOS и Android.
  - Полноэкранный автономный режим работы (standalone), кастомные splash-экраны и иконки.
  - Оптимизированные сенсорные элементы управления, запрет нежелательного зума полей ввода на iOS Safari.
- **Генерация и скачивание договоров**:
  - Быстрое скачивание договоров в форматах **PDF** и **DOCX (Word)** с актуальными параметрами и спецификацией.
  - Редактор спецификации товаров и услуг с автоматическим переносом позиций из вкладки «Материалы».
  - Адаптивный вид спецификации: сенсорные карточки на смартфонах и расширенная таблица на десктопе.
- **Канбан-доска**: Интерактивная доска заказов с поддержкой Drag-and-Drop.
- **Складской учет**: Управление остатками, ценами закупки и розничной продажи (`salePrice`), списание при добавлении в заказ.
- **История клиентов**: Быстрый переход к истории заказов конкретного клиента.
- **Подсказки адресов**: Интеграция с Dadata для автодополнения адресов при создании заявок.
- **Адаптивность**: Отзывчивый дизайн (Responsive UI) с поддержкой тёмной/светлой темы.

## ⚙️ Установка и запуск (Local Development)

### Требования
- Node.js (рекомендуется v20+)
- npm или yarn

### Шаги для запуска
1. Склонируйте репозиторий.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Скопируйте файл `.env.example` в `.env.local` и настройте переменные окружения:
   ```env
   VITE_API_URL=http://localhost:8080/api/v1
   VITE_DADATA_API_KEY=ваш_ключ_dadata
   ```
4. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
5. Откройте `http://localhost:5173` в браузере.

## 📦 Сборка для Production
```bash
npm run build
```

Сборка Docker-образа:
```bash
docker build -t altacrm-frontend:latest .
```
Или в составе всего стека через `docker-compose`:
```bash
docker-compose up -d --build frontend
```

## 🏗 Архитектура приложения
- `/src/api` - Axios инстансы и функции-хэндлеры для запросов к бэкенду (включая скачивание PDF и DOCX).
- `/src/components` - Переиспользуемые компоненты (Layouts, Modals, PWA Install Prompt).
- `/src/pages` - Страницы приложения (Канбан, Клиенты, Сотрудники, Склад, Настройки).
- `/src/store` - Глобальное состояние (Zustand: AuthStore, AppStore).
- `/src/styles` - Глобальные и компонентные стили с мобильными медиа-запросами.
