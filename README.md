# AltaCRM Frontend

AltaCRM — это современный клиентский веб-интерфейс и PWA (Progressive Web Application) для отраслевой CRM-системы натяжных потолков и строительно-отделочных услуг. Поддерживает Multi-Tenancy (изоляцию данных по компаниям), гибкую систему тарифов (Feature Gates), Канбан-воронку сделок, AI-аналитику аудиозвонков, оптическое распознавание документов (OCR), сметный калькулятор замеров, генерацию договоров (PDF/Word), расчет финансов и зарплат.

---

## 🛠 Технологический стек

- **Библиотека / Фреймворк**: React 18 (Hooks, Suspense, Portals)
- **Язык**: TypeScript
- **Сборщик**: Vite 6+
- **PWA**: `vite-plugin-pwa`, Workbox Service Worker (автономная работа, push-уведомления, установка на домашний экран)
- **Стейт-менеджмент**: Zustand (`useAuthStore`, `useAppStore`), React Query / Custom Hooks
- **Маршрутизация**: React Router v6
- **Стилизация**: CSS Custom Properties (темы: Dark / Light), Glassmorphism, Responsive CSS Grid / Flexbox
- **Иконки**: Lucide React
- **Интернационализация**: i18next (React-i18next)
- **Подсказки адресов**: React DaData
- **HTTP клиент**: Axios с централизованным перехватчиком ошибок, JWT-авторизацией и авто-подстановкой `X-Tenant-ID`
- **Тестирование**: Vitest, React Testing Library

## 🚀 Ключевые возможности

### 1. Интеллектуальный интерфейс Канбан-доски (Заявки)
- **Два режима отображения на мобильных**:
  - **Аккордеон-список (`List View`)**: компактная группировка по статусам воронки с быстрым разворачиванием/сворачиванием всех этапов.
  - **Горизонтальная доска (`Board View`)**: классический вид колонок с поддержкой плавного горизонтального скролла.
- **Интеллектуальный Touch Drag-and-Drop (`useTouchKanbanDrag`)**:
  - Защита от случайного захвата карточек при вертикальном и горизонтальном скролле (таймер долгого нажатия 500 мс, порог движения `MOVE_THRESHOLD = 8px`).
  - Полное исключение случайного открытия («провала в карточку») при жестах прокрутки.
  - Изменение порядка этапов воронки через выделенный сенсорный drag-handle (`useTouchColumnReorder`).
- **Быстрые действия в карточке**:
  - Звонок клиенту в один тап (`tel:`).
  - Прямой переход в WhatsApp и Telegram с предзаполненными сообщениями.
  - Построение маршрута в **Яндекс.Картах** / Навигаторе и **2ГИС**.
  - Напоминания по сделкам с цветовой индикацией (просрочено / на сегодня).
  - Завершение монтажа в 1 клик с валидацией Акта и выбором монтажника.

### 2. AI-ассистент и анализ звонков (YandexGPT + SpeechKit)
- Загрузка аудиозаписей звонков и встреч.
- Встроенный аудиоплеер с таймлайном.
- Автоматическая транскрибация речи на русском языке.
- Генерация структурированного саммари диалога и рекомендаций менеджеру по продажам.
- **Интерактивный AI-чат по сделке**: возможность задавать свободные вопросы нейросети на основе стенограммы разговора.
- Прозрачный учет затрат: отображение токенов LLM и стоимости каждого AI-запроса в рублях.

### 3. Распознавание паспортов и сканер документов (OCR)
- **`PassportScannerModal`**: моментальное распознавание фото/сканов паспортов РФ через Yandex OCR с автоматическим заполнением реквизитов клиента и договора (серия, номер, кем/когда выдан, код подразделения, ФИО, прописка).
- **`DocumentScannerModal` & `ImageCropModal`**: обрезка, поворот и коррекция документов перед загрузкой.
- **`ActUploadActionSheet`**: мобильный Action Sheet для быстрой загрузки фото Акта выполненных работ с камеры смартфона или из галереи.

### 4. Визуальный мастер замеров (Measurement Wizard)
- Пошаговый интерактивный конфигуратор натяжных потолков:
  - Расчет площади, периметра, диагоналей и полотен.
  - Учет углов, вырезов под трубы, багета и маскировочной ленты (вставки).
  - Освещение: точечные светильники, люстры, световые линии, трековые системы.
  - Автоматический расчет стоимости материалов и монтажных работ.

### 5. Генерация и печать договоров
- Мгновенное скачивание готового пакета документов в форматах **DOCX (Word)** и **PDF**.
- Полное автозаполнение всех приложений (Договор, Спецификация, Акт, Согласие ОПД, Гарантия).
- Интерактивный редактор спецификации товаров и услуг с синхронизацией из вкладки «Материалы».

### 6. Модульная система и Multi-Tenancy
- **`FeatureGate`** & **`useFeature`**: динамическое сокрытие модулей (AI, Склад, Сканер, Договоры) согласно тарифному плану текущей компании.
- **`CompanySwitcher`**: переключение между доступными филиалами/компаниями в реальном времени без повторного логина.

### 7. Финансы, Зарплаты и Аналитика
- **Финансы компании**: отчетность по доходам, себестоимости материалов, операционным расходам и чистой прибыли.
- **Зарплаты**: расчет заработка монтажников и замерщиков по тарифам за кв.м, точки освещения и процент от маржи.
- **Exit Intent Analytics**: аналитика брошенных заявок с калькулятора сайта.

## ⚙️ Установка и локальный запуск

### Требования
- **Node.js 20+**
- **npm** (или yarn / pnpm)

### Шаги установки:
1. Склонируйте репозиторий:
   ```bash
   git clone <repo-url>
   cd alta-crm-front
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Создайте файл конфигурации окружения `.env.local`:
   ```env
   VITE_API_URL=http://localhost:8080/api/v1
   VITE_DADATA_API_KEY=ваш_ключ_dadata
   ```
4. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
   Интерфейс откроется по адресу: `http://localhost:5173`

## 🏛 Структура проекта

```
│   ├── MeasurementWizard.tsx
│   ├── PassportScannerModal.tsx
│   ├── DocumentScannerModal.tsx
│   └── CompanySwitcher.tsx
├── constants/      # Константы, системные AI-промпты, конфигурации
├── features/       # Фичи (поиск клиентов, модалки ограничений перемещения)
├── hooks/          # Пользовательские хуки (useTouchKanbanDrag, useFeature и др.)
│   └── queries/    # React Query хуки для кэширования серверных данных
├── pages/          # Основные экраны CRM (Kanban, Clients, Finances, Storage и др.)
├── store/          # Zustand хранилища состояния (useAuthStore, useAppStore)
├── styles/         # Стили оформления, тема Glassmorphism, CSS-адаптивность
└── utils/          # Утилиты форматирования дат, аватаров, телефонов, карт
```
